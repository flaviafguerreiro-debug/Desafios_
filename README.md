# 🚀 Desafios de Análise de Dados e Automação (Python & Google Sheets)

Repositório dedicado a desafios práticos de engenharia e análise de dados, unindo programação em Python (com consumo de APIs) e tratamento estruturado de dados em planilhas na nuvem.

---

## 📂 Estrutura do Repositório

O projeto está organizado da seguinte forma:

| Arquivo / Pasta | Descrição |
| :--- | :--- |
| **[`Desafio1_API_Python.ipynb`](./Desafio1_API_Python.ipynb)** | Notebook desenvolvido no Google Colab focado em integração com API e manipulação de dados com Python. |
| **[`Desafio_01_Atendimento_Cliente.xlsx`](./Desafio_01_Atendimento_Cliente.xlsx)** | Base de dados estruturada no Google Sheets utilizada para análises operacionais e de indicadores de atendimento. |

---

## 🛠️ Tecnologias e Ferramentas Utilizadas

* **Python:** Linguagem principal para automação e manipulação de dados.
* **Google Colab:** Ambiente de desenvolvimento em nuvem para execução do notebook.
* **Pandas / Bibliotecas Python:** Utilizadas para  análise dos dados da API.
* **Google Sheets:** Organização, estruturação e consolidação de indicadores da base de atendimento em nuvem.

---

## 📊 Sobre os Desafios

### 1. Desafio de API com Python (`Desafio1_API_Python.ipynb`)
* **Objetivo:** Conectar-se a uma API externa, extrair dados em formato JSON, realizar a estruturação inicial utilizando o Python.
* **Destaques:** Preparação dos dados para análise.

### 2. Análise de Atendimento ao Cliente (`Desafio_01_Atendimento_Cliente.xlsx`)
* **Objetivo:** Consolidar e analisar métricas de atendimento ao cliente para suporte à tomada de decisão.
* **Destaques:** Foco em indicadores operacionais, organização de planilhas no Google Sheets e visualização de desempenho.
